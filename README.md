# 안개관

폭우로 고립된 저택에서 벌어진 살인 사건을 파헤치는 한국어 미스터리 텍스트 어드벤처 게임입니다. 브라우저에서 바로 실행되며, 별도 설치나 빌드 과정이 없습니다.

🔗 **플레이하기**: https://03jiho.github.io/angaegwan/

## 줄거리

어느 가을밤, 사업가 강태호가 자신의 저택 '안개관'에서 열린 만찬 도중 서재에서 싸늘한 시신으로 발견된다. 그날 저택에 있던 사람은 단 넷 — 아내 이수진, 동업자 박정민, 아들 오세훈, 그리고 집사 김도현. 폭우로 길이 끊겨 아무도 저택을 벗어나지 못했다. 범인은 지금도 이 안에 있다.

플레이어는 사건을 맡은 형사가 되어 여섯 개의 방을 돌아보며 단서를 모으고, 용의자들을 심문해 진범을 밝혀내야 한다.

## 실행 방법

위 링크를 열면 바로 플레이할 수 있어요. 파일을 내려받아 직접 열어도 됩니다:

`index.html` 파일을 브라우저로 열기만 하면 됩니다.

```bash
# 예시 (로컬에서 바로 열기)
start index.html
```

## 놀이법

- **저택 탐색**: 서재, 다이닝룸, 주방, 정원, 침실, 응접실 여섯 개 방을 돌아다니며 단서를 조사한다.
- **심문**: 용의자 네 명을 심문한다. 일부 대사는 관련 증거를 먼저 찾아야 열린다.
- **증거함**: 확보한 단서는 사이드바에서 언제든 다시 확인할 수 있다.
- **수사 메모**: 추리를 자유롭게 적을 수 있고, 브라우저에 자동 저장된다.
- **사건 종결**: 확신이 서면 용의자와 근거 증거를 선택해 범인을 지목한다. 틀려도 계속 수사할 수 있다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음, 파일 하나로 동작)
- 폰트: Google Fonts (Song Myung, Noto Serif KR, Noto Sans KR, IBM Plex Mono)
- 수사 메모는 `localStorage`에 저장됨 (게임 진행 상태는 새로고침 시 초기화)
